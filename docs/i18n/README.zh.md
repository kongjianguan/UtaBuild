# 双语文档

[English](README.md) | 中文

本仓库的文档使用英文和简体中文维护。本页定义配对契约、范围、排除项和职责分工；[translation-rules.md](translation-rules.zh.md) 定义如何生成对应文件；[terminology.md](terminology.md) 是术语真源。最近的文档说明定义轻量级撰写路径。

## 配对契约

- **两种语言同等有效。** 文档可以先用任一语言撰写和评审。对应文件从正在修改的一侧翻译而来；两种语言没有高低之分，且都必须表达同一个契约。
- **一组配对包含三个同目录文件。** 英文 `foo.md`、中文 `foo.zh.md` 和一致性记录 `foo.i18n.yaml` 必须位于同一目录。不要使用语言目录、独立翻译仓库或中英混排的单文件。配对必须作为一个整体合入。
- **一致性记录。** `foo.i18n.yaml` 保存上次确认时两侧各自完整的 Git blob hash：

  ```yaml
  foo.md: 3f786850e387550fdab836ed7e6dc881de23001b
  foo.zh.md: 89e6c98d92887913cadf06b2adb97f26cde4849b
  ```

  使用 blob hash 而不是 commit hash，可以用 `git hash-object` 为未提交文件计算记录。仓库可以把已确认的 blob 保存在内容寻址的 ref 下，使记录的恢复指针不受垃圾回收影响。配对失去同步时，应把被修改一侧的最小语义 diff 应用到另一侧，绝不能盲目整篇重译。评审确认两侧一致后，再刷新两个 hash。
- **语言切换行。** 中文文件必须紧跟 H1 标题，以 `[English](foo.md) | 中文` 链回英文。普通撰写的英文文件在相同位置以 `English | [中文](foo.zh.md)` 回链。若生成器拥有英文文件的全部字节，生成英文源可以省略切换行；中文对应文件仍必须链回英文。
- **结构与对应文件一致。** 标题层级和顺序、列表类型、有序列表起始编号、列表项数量、表格维度、围栏代码块以及语义链接目标必须一一对应。指向活跃双语语料的链接在两侧使用各自的目标语言后缀；范围外的链接保留原路径。

## 配对门禁

仓库的配对验证器机械地执行这份契约：

1. 范围内的每篇文档都有完整配对。
2. 每组已存在的配对都具备三个文件、最新 blob hash、必要的切换行、语言正确的内部链接和一致的结构签名。
3. 列入排除清单的文件不得存在 `.zh.md` 对应文件或 `.i18n.yaml` sidecar。
4. 冻结的归档记录使用专门的归档验证器，而不是持续演进的活动配对门禁。

结构签名通常包括标题深度、围栏代码块的信息字符串和正文、表格维度、列表类型、有序列表起始编号、列表项数量，以及保留 query 和 fragment 后缀的语义链接目标。由源代码派生的代码可以在围栏之间按字节比较，而不是重复编译两次。

验证器可以提供列出状态的模式，以及只检查指定配对的范围模式。限定范围的绿灯不能取代集成前的全语料检查。重新记录 sidecar 只能确认精确的文件内容，不能证明翻译准确、自然或术语一致；这些判断属于评审。

## 范围与排除项

活动范围通常包括根目录贡献和品牌文档、非 vendor README，以及 `.agents/notes/**`、`docs/**` 和仓库政策指定的其他目录中的当前文档。README 的发现应不区分 basename 大小写，并覆盖未来新增目录，而不需要逐文件维护上线清单。

当存在经过评审的中文对应文件时，生成的英文参考资料也属于配对范围。生成器仍是英文真源；重新生成英文后，中文对应文件需要经过评审才能重新同步。如果生成器同时拥有两种语言，可以投影配对路径，同时保持其他生成字节一致。

常见排除项包括：

- `AGENTS.md` 等指令文件及兼容性符号链接；
- 以双语方式编写的术语表和风格样例；
- 正文精确内容属于执行契约的机器消费翻译 prompt；
- 冻结的归档 Agent Note 及其封存三件套；
- 有意不提供评审对应文件的生成源。

在仓库的配对清单中明确记录排除项。不要用日期截止线或不断增长的手工白名单替代清晰的范围规则。

## 职责分工

工作 agent 在加载术语表后，直接用一次术语指导的流程更新发生变化的对应文件，同时保留未变化的正文和结构。仓库可以为显式调用提供翻译工作流或生成器，但不能隐藏普通契约，也不能让日常配对更新依赖不透明的交接。

门禁检查完整性、hash、切换行、结构形状和链接语言。评审检查含义、术语、语体以及源文档本身是否正确。生成源应在其源代码或生成器处修改，再重新生成；手工编辑生成的英文输出不是有效的配对修复方式。
