# 事故复盘（postmortem）

[English](README.md) | 中文

事故复盘记录触及用户、集成、发布版本或其他重要边界的失败。真正有价值的问题是流程为什么放过了它，而不只是那一行修复。

事故复盘不是 [Agent Note](../../.agents/notes/README.zh.md)。Agent Note 记录经过考虑的设计决策、被否决的替代方案或未来提案。事故复盘则回顾什么出了问题、机制是什么、现有防护为什么没有拦住，以及为使同类失败下次更早暴露而增加的具体防护措施。

当失败具有**隐蔽性**、**系统性**且**重新发现代价高**时，撰写事故复盘。链接该复盘推动建立的测试、说明、决策记录或运行防护。

每篇事故复盘都以**执行摘要**开头：用一段简短文字说明什么出了问题、根因是什么、为什么逃逸，以及可以长期复用的教训。随后补充理解和预防复发所需的详细证据。
